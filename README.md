# AI-Powered Chatbot

A conversational AI chatbot built with **Flask** and **Hugging Face Transformers**.

## Features
- Chat with AI in real-time
- Web interface
- Lightweight and simple

## Tech Stack
- Python, Flask
- Transformers (DialoGPT)
- HTML, CSS, JavaScript

## Run Locally
```bash
git clone https://github.com/YOUR-USERNAME/ai-chatbot.git
cd ai-chatbot
pip install -r requirements.txt
python app.py
