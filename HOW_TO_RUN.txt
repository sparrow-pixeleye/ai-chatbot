📋 PREREQUISITES
================
✅ Python 3.8 or higher
✅ pip (Python package manager)
✅ 4GB+ RAM recommended
✅ Internet connection (for AI APIs)

🔧 INSTALLATION STEPS
=====================

1️⃣ INSTALL DEPENDENCIES
------------------------
Run this command in your terminal:

    pip install -r requirements.txt

This will install all necessary packages including:
- Flask (web framework)
- AI model libraries (OpenAI, Gemini, etc.)
- Database components
- UI dependencies

2️⃣ OPTIONAL: SET UP AI API KEYS
--------------------------------
For the BEST experience, get API keys from:

🔹 OpenAI (GPT-4): https://platform.openai.com/api-keys
🔹 Google AI (Gemini): https://makersuite.google.com/app/apikey
🔹 Anthropic (Claude): https://console.anthropic.com/

Create a .env file and add your keys:
    OPENAI_API_KEY=your_key_here
    GEMINI_API_KEY=your_key_here
    ANTHROPIC_API_KEY=your_key_here

⚠️  NOTE: The system works WITHOUT API keys using the built-in local AI!

3️⃣ RUN THE APPLICATION
-----------------------
Start the server with:

    python app.py

You'll see this beautiful startup message:
============================================================
🚀 APRATIM'S AI 2.0 - Ultimate AI Assistant
============================================================
📅 Date: 2025-01-01 12:00:00
🤖 Available Models: ['gpt-4', 'gemini-pro', 'local-ai']
💾 Database: Connected
🌐 Server: Starting on http://localhost:5000
============================================================
✨ Ready to serve the most intelligent AI responses!
============================================================

4️⃣ OPEN YOUR BROWSER
---------------------
Navigate to: http://localhost:5000

You'll be greeted by the stunning APRATIM'S AI 2.0 interface!

🔧 TROUBLESHOOTING
==================

❌ "Module not found" errors
----------------------------
Solution: Run "pip install -r requirements.txt" again

❌ Port 5000 already in use
---------------------------
Solution: Use a different port:
    python app.py --port 8000

❌ AI responses seem basic
--------------------------
Solution: Add API keys for advanced AI models (see step 2)

❌ Voice features not working
-----------------------------
Solution: Use Chrome/Edge browser and allow microphone access

❌ Slow responses
-----------------
Solution: Check internet connection or try local-only mode
