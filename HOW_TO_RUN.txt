How to Run the AI Chatbot

This file explains how to set up and run the AI chatbot locally.

1. Prerequisites

Python 3.7 or higher

pip (Python package installer)

git (for cloning the repository)

Stable internet connection (to download model weights)

2. Clone the Repository
git clone https://github.com/sparrow-pixeleye/ai-chatbot.git
cd ai-chatbot

3. (Optional) Create a Virtual Environment
python -m venv venv
source venv/bin/activate      # On Windows: venv\Scripts\activate

4. Install Dependencies
pip install -r requirements.txt

5. Run the Chatbot
python app.py


Open your browser at: http://127.0.0.1:5000

Start chatting with the AI.

6. Troubleshooting

If you see missing packages → re-run pip install -r requirements.txt

If model fails to load → ensure internet connection and enough RAM

Use a smaller model if your system is low on memory
